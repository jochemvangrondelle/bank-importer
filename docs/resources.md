## Standards and Specifications

### Financial Data Formats

- **ISO 4217**: Currency codes (THB, USD, etc.)
- **ISO 3166-1**: Country codes (TH, US, etc.)
- **ISO 8601**: Date and time formats

### File Formats

- **CSV**: RFC 4180 - Common Format and MIME Type for Comma-Separated Values
- **JSON**: RFC 8259 - The JavaScript Object Notation (JSON) Data Interchange Format
- **PDF**: ISO 32000 - Document management - Portable document format
