# Release Notes

This page automatically displays the generated changelog from the build process. The changelog is automatically generated by [python-semantic-release](https://python-semantic-release.readthedocs.io/) based on conventional commits.

## About the Changelog

The changelog follows the [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) format and is automatically updated during the release process. The project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html):

- **MAJOR**: Breaking changes
- **MINOR**: New features (backward compatible)
- **PATCH**: Bug fixes (backward compatible)

### Changelog Sections

- **Added**: New features
- **Changed**: Changes in existing functionality
- **Deprecated**: Soon-to-be removed features
- **Removed**: Removed features
- **Fixed**: Bug fixes
- **Security**: Security fixes
