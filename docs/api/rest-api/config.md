# Configuration Endpoints

Configuration management endpoints for accounts, targets, and settings.

## GET /config

Get current configuration.

## PUT /config

Update configuration.

## GET /config/accounts

List all configured accounts.

## POST /config/accounts

Create a new account.

## GET /config/accounts/{account_name}

Get account configuration.

## PUT /config/accounts/{account_name}

Update account configuration.

## DELETE /config/accounts/{account_name}

Delete an account.

## GET /config/targets

List all configured targets.

## POST /config/targets

Create a new target.

## PUT /config/targets/{target_name}

Update target configuration.

## DELETE /config/targets/{target_name}

Delete a target.

See the [OpenAPI Specification](../openapi.md) for complete details.
